# ContextHop brand

The primary repository logo pairs two separate workspace windows with a hopping
arrow and the full **ContextHop** name. The windows represent isolated sessions;
the arc represents switching contexts.

- [Light-background logo](workspace-hop-light.svg)
- [Dark-background logo](workspace-hop-dark.svg)

Both SVGs have transparent backgrounds and a 960 × 260 viewBox. The repository
README uses a `picture` element to select the version for the reader’s theme and
displays it at 660 pixels wide. Use the complete lockup with its existing padding.
The wordmark uses Arial Bold with Helvetica and sans-serif fallbacks.

The dark version retains bright aqua and blue; the light version uses deeper
teal and blue for visibility against white. Keep the windows separate and the
hop arrow clear when adapting the design.
