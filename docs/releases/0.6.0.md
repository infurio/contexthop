# ContextHop 0.6.0

This release simplifies development and publishing. Terminal behaviour and catalog
configuration are unchanged; no migration is required.

- Release publishing now uses five jobs, combining candidate preparation and
  testing while preserving public-download and fresh Homebrew installation checks.
- Releases reuse successful full CI from a main-branch push for the exact tagged
  commit. Missing or unsuitable evidence triggers full checks before packaging.
- Reviewed release notes are included automatically in both release repositories.
- `scripts/record-demos` builds the current source into a temporary directory and
  pins that executable across demo sessions. Each recording uses isolated fictional
  data; installed and stale development binaries are not used. Recording remains
  separate from CI and release builds.
- Release helpers and their tests are grouped under `scripts/release/` and
  `scripts/tests/`. Python helper names now use underscores; contributor commands
  and workflow paths have been updated.
- The release guide now presents the normal steps first, with detailed testing,
  setup, and packaging guidance in expandable reference sections.
