# ContextHop 0.7.0

## Changed launch behaviour

The launch shortcuts have changed: Enter previously applied to the current shell,
and Shift+Enter opened a subshell.

Enter now runs **Update shared**: publish Selected as the shared config and follow it in
this terminal. Other following Zsh terminals adopt it at their next prompt or
before their next command. Running applications keep their startup environment.

- **Shift+Enter — Apply here:** apply only to this shell and pin its selection.
- **Option+Enter — Subshell:** open an isolated subshell.
- **Ctrl+G / Options → Join shared:** rejoin the existing shared config without
  publishing Selected. Also available as `chop shared use`.
- `chop shared clear` removes the shared config. Following terminals restore
  their original managed environment bindings; pinned shells stay unchanged.

When a shell is pinned, the header also shows the shared config it could rejoin.
Narrow terminals stack the shared preview beneath Active. The preview refreshes
while chop is open. Updating shared without integration saves the config and
prints instructions for making that terminal follow it.

## Upgrade

Reload integration in each existing terminal after upgrading, or open a new
terminal if your startup file already includes this line:

```zsh
eval "$(chop shell-init zsh --in-place)"
```

The development commands `chop default follow` and `chop default clear` remain
supported as aliases.
Existing native gcloud and Kubernetes configuration files are not rewritten.
A saved workspace is not required for shared, current-shell, or subshell use.

## Authentication and display fixes

- Authentication (`a`, also in Options) manages CLI and ADC login/logout separately.
  Authentication does not publish or change your shell selection. ADC logout
  revokes credentials for all applications using that file; shared CLI credentials
  may also require login again.
- ADC-enabled launches recover missing authentication, verify the ADC identity,
  and preserve valid ADC when only CLI login is required.
- Authentication descriptions wrap so the selected operation is readable.
- Active/Selected Kubernetes comparisons use the effective context and namespace.
- Prompt names use each item's first tag colour in alphabetical display order.
  `PROD` remains a text marker and does not force red. Reapply a selection to
  refresh an existing session after changing its tags or colours.
