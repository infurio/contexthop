# ContextHop 0.5.0

This release makes the terminal browser easier to read and keeps navigation stable
while filtering, staging resources, and resolving incomplete selections.

- Compare Active and Selected contexts in aligned columns, with a compact layout
  for small terminals. An `[ADC]` badge beside the identity shows when ADC is enabled.
- Navigate tabs within a single table border. Green labels identify tabs with staged
  selections, and a green cursor row makes a staged resource visible while browsing.
- Edit filters in the bottom border without moving the table headings. Esc keeps the
  query and returns to browsing; `/` resumes editing; another Esc clears the query.
  Left/Right and Tab switch tabs and preserve their filters and highlighted rows.
- Staging a workspace focuses its components on the next visit to each entity tab.
- Selection warnings, discovery feedback, and scope notices share a reserved header
  row on every tab, so they no longer move the tabs or table headings. Counts,
  hidden-resource metadata, and scrolling information share a consistent format.
- The footer displays the release version when space permits. The README includes
  new branding and refreshed demos using fictional data.

No configuration migration is required. While editing a filter, Esc now retains
results instead of clearing them immediately. Press Esc again to clear the filter
before continuing normal selection clearing.
