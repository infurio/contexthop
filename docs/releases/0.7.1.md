# ContextHop 0.7.1

## Clearer context comparisons

- Selected keeps more space on smaller terminals. The Shared comparison hides
  first, then Active; both return when the terminal grows. Short terminals use a
  compact preview to leave room for filtering and resource rows.
- ADC badges remain visible when long context values are shortened, including
  the shared configuration's identity.
- Header, footer, notice, and list rendering now share their display and layout
  rules. Staging, selection markers, filters, Options, Help, and launch shortcuts
  retain their existing behavior.

## More repeatable validation

Integration tests and demo recordings now share disposable environments and
fictional provider fixtures. Tests start independently of an inherited managed
shell, and recordings use the current checkout with isolated configuration.
The browsing and shared-context demos have been refreshed.

## Upgrade

No configuration migration is required. Authentication and shell activation
behavior are unchanged from 0.7.0, including Update shared, Apply here, Subshell,
and Join shared.
