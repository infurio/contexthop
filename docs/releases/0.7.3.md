# ContextHop 0.7.3

Fixes context labels accumulating in terminal prompts, including repeated blank
Enter presses in Ghostty. Prompt updates preserve terminal markers, shell
settings, other hooks, and theme changes. With Oh My Zsh, the label updates through
a stable prompt reference.

Choose whether integrated terminals display the prefix:

```sh
chop config prompt-prefix off
chop config prompt-prefix on
```

The default remains on. The saved preference applies to all integrated terminals
using the same configuration at their next prompt refresh. Context switching and
completion remain active when the prefix is hidden. Running
`chop config prompt-prefix` displays the current setting.

After upgrading, open a new terminal session or reload integration once:

```zsh
eval "$(chop shell-init zsh --in-place)"
```

If an old session already has accumulated labels, open a new session to start with
a clean prompt. No configuration migration is required.

Release uploads now use a Linux runner after the macOS candidate passes native
checks. Archive integrity checks, downloaded-asset comparisons, and public
Homebrew installation checks remain in place.
