# Code of conduct

Treat participants respectfully in issues, pull requests, and other project
spaces. Welcome questions and constructive criticism. Discuss behaviour and
technical decisions without personal attacks.

Harassment, threats, discriminatory language, spam, and publishing someone
else's private information are not acceptable. Do not post credentials or
private account and infrastructure details.

Maintainers may edit or remove content, close discussions, or restrict
participation to keep project spaces useful and welcoming. Use GitHub's
[reporting tools](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam)
to report abuse or private-information exposure. Report software vulnerabilities
through the separate [security reporting channel](SECURITY.md).
